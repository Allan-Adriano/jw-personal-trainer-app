# JW Personal Trainer App

Mobile app for workout management and student tracking.

## 📋 Sobre o Projeto
Aplicativo mobile voltado para organização e acompanhamento 
de treinos focados em saúde, hipertrofia e emagrecimento, 
desenvolvido para a JW Personal Trainer.
